# taotao-contract · Impl 切片

## 自门控

Plan 中没有「契约落地与代码生成」任务 → 跳过。

## 开工前

1. 运行生成命令，确认生成物与仓库中已提交的一致（`git status` 无 diff）；有漂移说明有人手改了生成代码或契约没重新生成，先停下告诉用户。
2. 交给实现子 agent 的派发内容中加入：契约文件路径 + "接口签名、字段、错误码以契约为准；生成目录不要手改"。

## 每个接口任务完成后

- handler / RPC 实现使用生成的类型，不另起一套同名结构体；
- 错误码与契约 `responses` / proto status 一致；
- 有 Prism mock 时，可以用同一组请求分别打 mock 与本地服务，对比响应结构（字段名、类型）是否一致。

## 产出

在 tt:impl 的收尾报告中加一行：`契约：生成物无漂移 ✓ / 实现与契约一致 ✓ / 发现偏差 <列表>`。
