# 禁止清单

> 命中即打回，不需要讨论。tt:impl 命中这里任一条会硬阻断。复盘后追加项目专属红线。

## 代码层

- **禁止 SQL 字符串拼接**：必须用占位符 / ORM 参数绑定
- **禁止 `exec.Command("sh", "-c", ...)` 拼接外部输入**
- **禁止吞错误**：`_ = f()` 丢弃 error 必须附注释说明原因
- **禁止使用 `http.DefaultClient` / 无超时的外部调用**
- **禁止把内部错误详情（堆栈、SQL）直接返回给调用方**
- **禁止调试输出残留**：`fmt.Println`、`spew.Dump`、临时 `log.Printf`（由 CR 判定；`cmd/` 下的命令行输出除外。提交门禁只做提示，不拦截）
- **禁止在库代码中 `panic`**（初始化阶段 `Must*` 除外）
- （填写，项目专属）

## 架构层

- **禁止 handler 直接访问 DB / 缓存**：经过 service / repo
- **禁止跨业务模块引用 internal 实现**：通过接口或公共包
- **禁止在没有隔离方案的情况下修改 hub 包**（被依赖最多的包，见 docs/knowledge/packages.yaml）
- （填写）

## 安全层

- **禁止提交凭证**：token、密码、私钥、AK/SK（包括测试环境）
- **禁止信任外部输入**：HTTP 参数、MQ 消息、DB 读出的数据都要校验
- **禁止绕过鉴权**（内部接口也不行）

## 依赖层

- **禁止未评估就引入新依赖**：先在 tech-selection.md 登记
- **禁止 `replace` 指向本地路径后提交**

## 上线层

- **禁止未经测试环境验证上线**
- **禁止高风险改动不带开关全量上线**
- **禁止 migration 无回滚方案**
