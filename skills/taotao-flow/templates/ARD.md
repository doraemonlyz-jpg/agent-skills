## 2. 背景与目标

- **业务背景**：从技术视角复述 PRD，说清为什么要做。

## 4. 业务规则

- **状态机**：列出全部状态与合法转换（可用表格或 mermaid）。
- **数值/计算规则**：公式、取整、上下限。
- **校验规则**：前置条件，失败时返回什么。
- **并发规则**：同一资源并发修改时的结果与防重手段。
- **幂等要求**：哪些接口必须幂等，幂等键是什么。

## 5. 接口与数据契约（需求层面）

- **对外接口清单**：新增/变更哪些接口，调用方是谁（字段细节留到 Design）。
- **下游依赖**：调用哪些服务/接口，各自 SLA。
- **数据变更范围**：表 / 字段 / 索引 / 缓存 key / MQ topic。
